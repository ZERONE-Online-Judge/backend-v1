# ZOJ에서 내 Editor 문제 가져오기

문제 관리의 **Editor에서 가져오기**에서 동일한 인증 이메일의 본인 소유
문제를 폴더·검색·페이지별로 조회합니다. 공유받은 다른 사람의 문제는
표시하지 않습니다. 참가 유형과 새 문제 번호를 선택해 등록합니다.

Editor에서 커밋한 공유 리비전만 사용합니다. 개인 작업 사본의 변경은
자동 커밋하거나 폐기하지 않습니다. 패키지가 없으면 Editor 워커가 전체
검증을 수행합니다. 검증 완료 후 ZIP의 SHA-256과 저장된 리비전을 확인하고
ZOJ의 기존 ZIP 가져오기와 동일한 트랜잭션으로 등록합니다. 채점 번들도
자동 준비합니다. 같은 요청을 재시도해도 문제를 중복 생성하지 않습니다.

ZOJ 백엔드 환경변수:

```dotenv
EDITOR_API_URL=https://editor.zoj.kr/api
EDITOR_BRIDGE_SECRET=<Editor의 EDITOR_ZOJ_BRIDGE_SECRET과 같은 별도 키>
EDITOR_CA_FILE=
```

운영에서는 HTTPS와 신뢰할 수 있는 인증서가 필요합니다. Editor는
`EDITOR_ZOJ_BRIDGE_SECRET`을 서버에만 보관하고 일반 로그인 토큰이나
쿠키를 전달받지 않습니다. 서버 요청은 목적·경로·본문·이메일·시간을
서명하며 일회성 nonce로 재전송을 차단합니다.

각 조회/검증/등록 요청에서 현재 `contest.problem.manage` 권한을 검사하고,
등록 트랜잭션 안에서도 권한을 다시 검사합니다. 대회 변경 잠금과 기존
문제 번호 충돌 검사를 유지합니다. 운영 로그에 출처 리비전을 기록합니다.
