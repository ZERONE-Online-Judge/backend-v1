# 대회 자동 긴급 공지

시작·프리즈·종료 안내는 **예정 시각당 공지 한 개**로 유지합니다. `notice-worker`가 해당 시각 30분 전부터 처음 확인할 때 한 번 발행합니다. 이후 남은 시간은 참가자 배너, 공지 본문, 운영자 화면에서 매초 계산합니다.

예: `대회 시작까지 30분 남았습니다.` → `29분 59초` → `29분` → `대회가 시작되었습니다.`

10·5·1분 전이나 시각 도달 시에 새 공지를 추가하지 않습니다. 새 공지/일정 변경 데이터는 기존 조회 주기(참가자 대회 정보 15초)로 받고, 이미 받은 카운트다운은 별도 요청 없이 동작합니다. 백그라운드 탭을 다시 열면 현재 시각으로 즉시 보정합니다.

## 운영자가 사용하는 명령어

공지 작성 또는 긴급공지 관리에서 카운트다운 버튼을 누르면 명령어가 들어갑니다. 입력창에는 원문을, 미리보기에는 참가자에게 보이는 실제 문장을 표시합니다. 일반 문구와 함께 사용할 수 있습니다.

| 명령어 | 기준 | 도달 시 문구 |
| --- | --- | --- |
| `{{countdown:start}}` | 현재 대회 시작 시각 | 대회가 시작되었습니다. |
| `{{countdown:freeze}}` | 현재 프리즈 시각 | 스코어보드가 프리즈되었습니다. 이후 제출 결과는 스코어보드에서 잠시 숨겨집니다. |
| `{{countdown:end}}` | 현재 종료 시각 | 대회가 종료되었습니다. 수고하셨습니다. |

자동 공지는 `{{countdown:start@2026-09-23T08:00:00+00:00}}` 형태로 당시 예정 시각을 함께 저장합니다. 따라서 일정 변경 뒤에도 과거 공지의 기준 시각은 유지됩니다. 직접 삽입하는 기본 명령어는 현재 설정 시각을 따릅니다. 세 가지 명령어만 해석하며 코드를 실행하거나 HTML을 삽입하지 않습니다.

## 발행·노출 규칙

- 초안·일정 미정·보관된 대회에는 자동 발행하지 않습니다. 시작 전에는 시작 안내만 발행합니다.
- 프리즈 모드가 `live`이면 프리즈 공지를 발행하지 않습니다. 기존 프리즈 카운트다운은 실시간 갱신 안내로 바뀝니다. 수동 `frozen` 모드는 프리즈 완료 안내를 표시합니다.
- 서버가 시각을 놓친 경우 10분 이내에는 한 번 발행할 수 있습니다. 종료된 대회에는 시작 안내를 뒤늦게 발행하지 않습니다.
- 같은 대회·일정 종류·예정 시각은 중복 발행하지 않습니다. 일정이 바뀌면 새 시각의 공지를 발행할 수 있습니다.
- 배너에는 마지막으로 반영된 공지 하나가 표시됩니다. 나머지는 공지 목록에서 확인합니다. 운영진이 문구를 덮어쓰거나 내리면 매초 갱신이 그 조작을 되돌리지 않습니다.
- 참가자가 닫은 카운트다운은 숫자가 바뀔 때마다 다시 나타나지 않습니다. 완료 단계 또는 새 일정으로 바뀌면 한 번 다시 표시됩니다. 완료 안내를 닫으면 다시 뜨지 않습니다.
- 기존 자동 사전 안내가 있으면 같은 공지를 카운트다운으로 전환합니다. ID와 게시 시각을 유지하며 운영진의 수정 문구나 새 긴급 배너는 덮어쓰지 않습니다.
- 자료 공개 범위는 그대로 적용합니다. 숨겨야 하는 긴급 공지는 원문 명령어도 함께 숨깁니다.
- `FEATURE_EMERGENCY_NOTICE_AUTO=false`는 자동 발행을 중지합니다. 직접 작성한 카운트다운의 화면 표시는 유지합니다.

## API 호환성

기존 `emergency_notice` / `body`에는 조회 시각에 계산한 문장을 반환합니다. 명령어가 있으면 `emergency_notice_template` / `body_template`에 원문도 반환합니다. 새 화면은 원문을 매초 해석하며, 편집·저장 시에도 원문을 유지합니다. 명령어가 없는 공지와 기존 클라이언트는 기존 텍스트 필드를 계속 사용할 수 있습니다. DB 스키마 변경은 없습니다.
