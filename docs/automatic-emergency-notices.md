# 대회 자동 긴급 공지

`notice-worker`가 서버 시각을 기준으로 확인합니다. 기본 확인 주기는 2초이며, 참가자 화면은 대회 정보를 15초마다 갱신합니다.

| 대상 | 사전 안내 | 시각 도달 시 |
| --- | --- | --- |
| 대회 시작 | 30·10·5·1분 전 | 대회가 시작되었습니다. |
| 스코어보드 프리즈 | 30·10·5·1분 전 | 스코어보드가 프리즈되었습니다. 이후 제출 결과는 스코어보드에서 잠시 숨겨집니다. |
| 대회 종료 | 30·10·5·1분 전 | 대회가 종료되었습니다. 수고하셨습니다. |

- 초안·일정 미정·보관된 대회에는 발행하지 않습니다. 시작 전에는 시작 안내만 발행합니다.
- 프리즈 모드가 `live`이면 프리즈 안내는 발행하지 않습니다. 시작·종료 안내는 유지합니다.
- 서버 재시작 등으로 시각을 잠시 놓친 경우 도달 후 10분 이내에는 해당 이벤트를 발행합니다. 종료된 대회에 시작 공지를 뒤늦게 발행하지 않습니다.
- 같은 대회·예정 시각·안내 단계는 한 번만 발행합니다. 일정이 변경되면 변경된 시각 기준으로 다시 안내할 수 있습니다.
- 공지 목록에 기록하고 긴급 공지 배너에 반영합니다. 배너에는 가장 최근에 반영된 내용 하나만 표시하며, 이전 내용은 공지 목록에서 확인합니다. 짧은 대회에서 시작과 이후 일정의 사전 안내가 함께 생성되면 시작 안내가 배너에 먼저 보입니다.
- 참가자가 닫은 배너는 같은 문구에 대해 다시 표시하지 않습니다. 다음 단계로 문구가 바뀌면 새 배너가 표시됩니다.
- `FEATURE_EMERGENCY_NOTICE_AUTO=false`이면 자동 발행을 중지합니다. 운영진이 직접 작성하는 공지에는 영향을 주지 않습니다.

시작 안내는 화면에서 별도로 계산하지 않고 프리즈·종료와 같은 서버 공지 경로를 사용합니다.
