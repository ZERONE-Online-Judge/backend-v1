# 운영 통계

서비스 마스터가 `/admin/analytics`에서 조회합니다. 대회 마스터·운영진·참가자·비로그인 이용자는 통계를 조회할 수 없습니다. 개인정보처리방침의 서비스 이용 통계 항목도 함께 배포해야 합니다.

## 수집과 집계

- `POST /api/public/usage`: 허용된 페이지의 첫 진입 및 경로 이동. 자동 API 갱신은 페이지 조회로 세지 않습니다. 같은 이벤트 ID의 30초 heartbeat는 화면 표시 시간과 최근 활동 시각만 갱신합니다.
- 방문자는 브라우저의 무작위 식별자 기준입니다. 탭별 세션은 30분 비활성 후 새로 시작합니다. 기기·시크릿 모드·저장소 삭제에 따라 같은 사람이 다른 방문자로 보일 수 있습니다. 저장소를 사용할 수 없으면 현재 문서의 메모리를 사용합니다.
- 화면이 보이는 동안의 근사 시간을 기록합니다. 장시간 열린 화면은 23시간마다 새 측정 구간을 시작합니다. 측정 요청은 인증 세션을 연장하거나 인증 오류 모달을 띄우지 않습니다.
- 기간·요일·시간대는 한국시간입니다. 하루를 선택하면 시간별, 여러 날이면 날짜별 추이를 반환합니다. 빈 구간은 0이며 미래 구간은 구분합니다. 오늘을 포함한 이전 기간 비교는 같은 경과 시간까지 비교합니다.
- 로그인 계정 수는 HMAC 처리한 계정 키의 중복 제거 값입니다. 이용자 구분은 화면을 열 때의 인증 상태를 기준으로 합니다. 이미 참가자로 등록된 회원은 참가자, 운영 권한이 있는 회원은 운영진으로 분류하며, 해당 대회의 참가자 미리보기는 별도입니다.
- 대회·화면마다 방문자가 중복될 수 있어 개별 표의 방문자 합계는 전체 고유 방문자 수와 다릅니다. 이전 방문 여부는 조회 시작일보다 앞선 보관 기록을 기준으로 합니다.
- 제출·채점 결과·질문·인증·운영 실패는 기존 기록의 집계입니다. **기간과 대회 필터만** 적용됩니다. 일반 로그인에는 대회 ID가 없으므로 대회를 선택하면 해당 대회가 명시된 인증 기록만 집계합니다. 채점 결과 대기는 제출 시각부터 현재 최종 판정 갱신 시각까지이며 재채점도 영향을 줍니다.

## 보관과 보호

이벤트·방문자·세션·계정 식별자는 서버 비밀키로 HMAC 처리합니다. 새 통계 테이블에는 이메일, IP 주소, 원본 User-Agent, 원본 URL, 검색어, 인증 토큰, 제출 코드, 문의 내용이 저장되지 않습니다. 대회 ID와 허용된 화면 종류만 남기며 외부 유입은 알려진 서비스 종류 또는 기타 외부로 분류합니다.

DNT/GPC 신호, 알려진 봇, 다른 출처의 브라우저 요청은 제외합니다. 익명 브라우저 요청은 조작되거나 차단될 수 있으므로 이 통계는 이용 추이를 위한 근사치이며 보안 감사나 과금의 근거로 사용하지 않습니다.

요청 제한은 프로세스별 메모리에서 브라우저당 분당 60회, 네트워크당 분당 3,000회입니다. 네트워크 제한은 배포 프록시가 덮어쓰는 `X-Real-IP`를 사용하며 원본 IP를 저장하지 않습니다. 여러 워커의 제한은 독립적입니다. 동일 이벤트에 동시 요청이 와도 DB 기본키 충돌 처리로 중복 조회를 방지합니다.

상세 기록은 395일 보관합니다. notice worker가 시작 시 및 매시간 최대 10,000개씩 오래된 기록을 삭제하고, 잔여 분량은 1분 뒤 이어서 정리합니다. 브라우저 식별자도 395일 후 재발급됩니다. CSV 내보내기는 현재 조회 결과이며 수식으로 해석될 수 있는 문자열은 이스케이프합니다.

## 배포

1. `0028_usage_analytics` 마이그레이션을 적용하고 API 및 notice worker를 배포합니다.
2. 프런트엔드와 개인정보처리방침을 배포합니다. 페이지 방문 통계는 이 시점 이후부터 수집되며 과거 방문을 복원하지 않습니다.
3. 서비스 마스터로 운영 통계에 접근하고 정상 집계를 확인합니다.

긴급하게 수집만 중단하려면 API 환경변수 `FEATURE_USAGE_ANALYTICS=false`를 설정하고 API를 재시작합니다. 기존 기록 조회 및 보관 기간 정리는 계속 동작합니다. `AUTH_TOKEN_SECRET`을 변경하면 식별자 연결도 끊어지므로 이후 방문은 새 방문자로 집계됩니다.
